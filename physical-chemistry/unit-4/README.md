# Unit 4 — Physical Chemistry notes reconstruction

## Purpose
Create a complete, explanatory, source-preserving study resource from the supplied 19-page handwritten Unit 4 notes.

## Source
`source/original-notes.pdf` is the primary source. Rendered archival pages are kept in `assets/source-pages/` and ten focused source figure extracts are stored in `assets/figures/`.

## Generation and QA
The 19-page PDF scan was rendered at 180 dpi and visually inspected page by page. Figure extracts were retained with labels and nearby annotations. The chapter was written in the source order, exported to DOCX and PDF, and reviewed using a rendered page contact sheet. The Word file currently uses formatted Cambria Math paragraphs rather than genuine editable OMML equations; that limitation is explicitly recorded in the audit documents.
